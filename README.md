# WindowOpacity · 窗口透明度工具

轻量的 Windows 桌面工具，通过窗口顶部悬停菜单或组合键 + 鼠标滚轮，调整指定窗口的不透明度。

适用于 Windows 10 / 11 的 64 位桌面环境。免安装，解压后即可运行，无需额外安装 .NET 或其他运行库。

## 下载与运行

前往 [Releases](https://github.com/zhiqianzheng/WindowOpacity/releases/latest)，下载 `WindowOpacity-v1.3.0-windows-x64.zip`，解压后双击 `WindowOpacity.exe`。

程序默认在系统托盘后台运行。若任务栏没有显示图标，可展开托盘的隐藏图标区域。

Release 同时提供 `SHA256SUMS.txt`，可在 PowerShell 中校验下载的压缩包：

```powershell
Get-FileHash .\WindowOpacity-v1.3.0-windows-x64.zip -Algorithm SHA256
```

## 功能

- **顶部悬停菜单**：鼠标停在目标窗口上边沿约 0.3 秒，弹出透明度滑块，移开后自动收起。
- **组合键 + 滚轮**：调整鼠标下方的窗口，无需先点击或激活它。
- **自定义调整幅度**：每格滚轮可以调整 1–100 个百分点，默认 5 个百分点。
- **自定义组合键**：支持 Shift、Ctrl、Alt、Win，允许组合使用。
- **多个窗口独立调整**：分别设置不同窗口的不透明度。
- **恢复原始状态**：支持恢复单个窗口、恢复全部窗口，正常退出时也会自动恢复。
- **开机自启动选项**：登录 Windows 后自动在托盘后台运行，不弹出控制面板。

## 使用方法

### 通过顶部菜单调整

1. 将鼠标移到目标窗口的上边沿，稍作停留。
2. 在弹出的菜单中拖动滑块，实时调整当前窗口。
3. 点击“恢复”，还原该窗口调整前的状态；鼠标移开后菜单自动隐藏。

操作悬停菜单时，工具不会主动抢走原窗口的键盘焦点。拖动滑块期间，菜单会保持展开。

### 通过滚轮调整

默认组合键为 **Shift**。鼠标可以停在目标窗口的任意位置：

| 操作 | 效果 |
| --- | --- |
| Shift + 向上滚动 | 增加不透明度，窗口更清晰 |
| Shift + 向下滚动 | 降低不透明度，窗口更透明 |
| 松开 Shift 后滚动 | 恢复正常滚轮操作 |

不透明度范围为 **1%–100%**：100% 表示完全不透明，1% 表示接近完全透明。工具不会将窗口设为完全不可见的 0%。

使用透明度快捷键时，该次滚轮操作会被工具拦截，避免同时滚动应用内容。

### 修改滚轮幅度和组合键

右键托盘图标，选择 **“设置（滚轮幅度 / 开机启动）…”**：

1. 选择需要按住的组合键，至少勾选一项。
2. 在“每格透明度变化”中输入 1–100 的整数，例如 `1`、`3` 或 `10`。
3. 点击“保存设置”，立即生效，并在重启程序后保留。

例如，从 80% 不透明度开始，每格设为 3%，向下滚动一格会变为约 77%。到达上下限后不会继续超出范围。

取消“启用滚轮调节透明度”并保存，可以关闭滚轮快捷键。顶部悬停菜单也可在托盘右键菜单中单独启用或暂停。

### 设置开机自启动

在上述设置窗口中勾选 **“开机自启动（登录后在托盘后台运行）”**，然后点击“保存设置”。下次登录 Windows 后，程序会自动在托盘运行。

取消勾选并保存，即可关闭自启动。自启动仅针对当前 Windows 用户，无需管理员权限；启用后请保留 EXE 的位置，若移动程序，需在新位置重新勾选并保存。

### 手动选择窗口与退出

单击托盘图标可打开控制面板，通过窗口列表和数值输入手动设置，也可以恢复所选窗口或全部窗口。

关闭控制面板后，程序仍在托盘运行。需要彻底退出时，右键托盘图标，选择 **“退出并恢复全部窗口”**。

## 使用限制

- 调整以管理员权限运行的窗口时，需要以管理员身份运行本工具。
- 部分特殊分层渲染窗口不支持安全调整，工具会提示并跳过。
- 调整的是整个窗口，包括其中的文字和图片；不提供仅背景透明的玻璃效果。
- 退出恢复指正常退出。若进程被强制结束，可能无法执行恢复。
- 当前不会记住每个应用的透明度并在其下次打开时自动应用；会保存组合键和滚轮幅度等工具设置。

## 源码与编译

使用 C++17 和 Windows 原生 Win32 API 实现。

| 文件 | 用途 |
| --- | --- |
| `main.cpp` | 透明度控制、悬停菜单、滚轮快捷键、托盘和设置界面 |
| `app.manifest` | 应用权限、Windows 兼容性和 DPI 声明 |
| `app.rc` | 版本信息及应用清单资源 |

安装包含 `g++` 和 `windres` 的 MinGW-w64 工具链后，在源码目录中执行：

```powershell
windres app.rc -O coff -o app.res.o
g++ main.cpp app.res.o -o WindowOpacity.exe -std=c++17 -O2 -Wall -Wextra -Wpedantic -Werror -municode -mwindows -static -static-libgcc -static-libstdc++ -lcomctl32 -ldwmapi -lgdi32 -luser32 -lshell32 -ladvapi32 -s
```

也支持以下启动参数：

```powershell
.\WindowOpacity.exe --panel       # 打开控制面板
.\WindowOpacity.exe --background  # 在托盘后台启动，重复启动时不弹出面板
```

设置文件保存在 `%LOCALAPPDATA%\WindowOpacity\settings.ini`。开机自启动通过当前用户的 Windows `Run` 注册表项管理，取消自启动只移除本工具自己的登记项。
